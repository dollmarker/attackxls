## 填写清单（对着扫描器输出逐项抄）

| 报告里的位置 | 从哪来 |
|---|---|
| `<N>` 名泄露人数 | 列语义核验里「身份证」列的**行数**（不是全文去重数） |
| `<M>` 身份证号数 | 同上；若两者不一致，报告里说明差异原因 |
| `<P>` 手机号 / `<B>` 银行账号 / `<A>` 住址 | 统计行；银行卡注明是 Luhn 口径还是 16–19 位口径 |
| 样例号 | `--show-full` 取 2~3 条，**报告里做前 6 后 4 脱敏** |
| 源表字段列表 | 扫描器输出的「表头」行 |
| 泄露载体 | `★ 未脱敏数据载体` 段里的 entry 名（`xl/externalLinks/externalLink1.xml`） |
| 内部信息（可选） | `⚠ 外部数据源落盘路径` + `· 文档属性` |
| 字节数 / 状态码 | 输出头部的 `HTTP=` 与 `bytes` |

## 三条写作纪律

1. **匿名性要写实**：明确"未登录、无 Cookie、搜索引擎公开索引可达"，这是定级的关键。
2. **数量只给一个口径**：正文用列语义口径，注释里可提全文口径的差异，别在同一段里混着写。
3. **样例从简**：报告正文 2~3 条即可，够证明真实性；完整数据只留在本地证据目录，不进报告、不上传。
